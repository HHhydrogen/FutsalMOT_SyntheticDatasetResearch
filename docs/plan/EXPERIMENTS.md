# 实验方案

## 1. 研究问题与实验组织

目标是检验足球合成数据能否改善真实比赛感知、替代部分目标域人工标注，以及收益能否在独立比赛中复现。BBox、人物实例Seg和Pose分别建立任务契约与真实评价，不合成一个总分，也不由数据字段齐全推定全部任务有效。

本文件规定研究思路、对照、数据、训练流程、预算与评价规则。实验结果、运行状态、失败、参数变更理由与审批沿革统一写入[实验日志](../exp/EXPERIMENT_LOG.md)；待办与实际实现差距写入[TODO](TODO.md)。数据来源和目录契约见[数据方案](DATASET.md)，论文主张边界见[论文方向](PAPER.md)。这些文档不替代各run冻结的实际参数与原始证据。

| 研究问题 | 必要比较 | 能回答的问题 |
|---|---|---|
| 固定计算下替换真实重复曝光 | 等总更新的R与R+S | 合成样本替换部分R曝光是否改善真实检测 |
| 两阶段的来源效应 | 同预算、同调度的短S→R与短R→R | 第一阶段用S而非R的增量 |
| 阶段拆分的影响 | 短R→R与单阶段R | 重启学习率/优化器/EMA的整体影响 |
| 真实标注效率 | 同一低标注池的R与一个固定合成方法，并参考全量R | 同标注量的增益及达到目标性能所需标注量 |
| 跨比赛泛化 | 方法冻结后的独立比赛评价、配对训练seed | 收益是否超出已反复使用的开发范围 |

### 1.1 范围与顺序

BBox主规格为YOLO11s，R+S固定1:1为合成候选。执行顺序为：seed17的50%纯R→50%混合→10%纯R→10%混合四项；其后seed29再seed43，各按100%/50%/25%/10%的纯R→混合顺序复现，共新增16项；最后复用三seed四档两方法的24个末步EMA，对两场独立于当前训练/开发的比赛统一评价。已有seed17的100%与25%四组只复用完整结果，不重跑。所有训练均1500成功更新/独立公开起点，逐项完整验收/GPU释放后接续，任何一项不以分数为条件取消另一方法。

首次新数值配置须建立实际数值与恢复证据；已完成重复验证的BBox标注曲线配置在seed29/43的16项复现中复用既有证据，不逐项重复CPU测试或GPU机械预检。各项仍保留来源绑定、完整资源、截止时间、进程互斥与结束收据检查。训练随机性与独立比赛确认承接固定配方，不依据确认成绩改LR、比例、预算、子集或选best。旧训练观察史保留，不将重复开发集当独立确认。Seg优先GT与CPU适配，Pose继续关节/比赛核验，均不训练或GPU预检；n/m/l/x、第二真实面板、号码和MOT不在本队列。

旧S3000→R截断前缀诊断退出主结果与方法选择，不用作新两阶段实验的初始化；其执行历史、观察史和原始证据在实验日志中保留。历史长预算实验不作为默认续训入口。

### 2.1 BBox面板

|---|---:|---:|---|
| SoccerNet | 2100唯一整图，3场/14clip | 750图，1场/5clip | 球员与门将；同一组内保持原UID/GT/有序图池 |

真实入口为G:/FutsalMOT_Dataset/real/soccernet/dataset.json；合成引用正式发布索引及原版本血缘，不复制4K媒体。已验收无损960输入缓存可复用，但必须绑定cache.json摘要、完整source binding和READY验收；不因缓存改变数据版本、GT、UID、增强或曝光定义。

### 2.2 BBox目标与ignore

保留公开COCO80检测头，训练目标为person类0，不用single_cls或随机重建单类头。源标注中GT flag=1且明确为裁判/staff/ball等非球员角色的目标作为已知背景；invalid_gt_flag或unknown_role才作为明确真实ignore。训练派生role_policy_v2记录原角色与处理去向，原GT只读。

ignore仅对框内未匹配anchor中心屏蔽负分类BCE，球员正匹配优先，box/DFL与正样本归一化保持。缺乏几何/语义真值时不制造ignore。标准主评价若存在无法可靠计分的真实ignore，则停止该评价准入，不把普通人物伪标为iscrowd。

### 2.3 划分与观察史

既有SoccerNet 750图明确作为开发集。独立确认集按比赛而非相邻帧划分；同比赛不同clip不算新的独立比赛。方法和参数冻结前不读取封存test或通过其成绩选策略。原GT、历史划分、已访问数据和既有预测记录不改写；新划分须另有明确UID清单与观察史。

## 3. BBox共用训练协议

### 3.1 计数、初始化与采样

一个update是一次成功optimizer.step，microbatch不单独计更新。有效batch固定16；每步累计曝光等于成功消费的R/S图数，唯一标注量与重复曝光分列。采样器按固定洗牌循环消费，末批跨轮补齐并记重复UID，不复制文件充数量。预取不推进已提交游标，成功更新后才提交采样位置。

每项独立实验从绑定的公开yolo11s.pt开始，不能从既有R/SR或诊断模型续训。训练seed固定Python/NumPy/Torch CPU/CUDA、独立loader generator与域采样流；记录确定性选项和完整状态。阶段间承接本实验上一阶段raw，重新创建SGD与EMA，不能把上一阶段EMA误当raw。

### 3.2 固定数值参数

| 项目 | BBox规则 |
|---|---|
| 模型/训练层 | YOLO11s/COCO80头，所有原可训练层；框架固定DFL投影等按原实现记录 |
| 输入 | 原RGB直接等比例LetterBox到960×960，auto=False、scale_fill=False、scaleup=True、center=True、pad114、INTER_LINEAR |
| 批次/加载 | micro8×2累积为有效16，workers2；同实验对照保持同分组 |
| 精度 | FP32，关闭TF32，确定性算法，cuDNN benchmark=False |
| 优化器 | 显式SGD Nesterov；momentum .937，weight组WD .0005，bias/norm组0 |
| 梯度 | 完整累积后L2 clip10，记录裁剪前后范数 |
| 损失 | box7.5 / cls.5 / dfl1.5；无Pose/mask/号码或新增域权重 |
| EMA | decay=.9999，tau=2000；按本阶段成功更新计数，阶段0从raw初始化 |
| 模型选择 | 固定末阶段末步EMA；不best、不按开发分数早停、不从raw/EMA取高者 |

若criterion返回已经乘micro图数的loss，则每micro反向L_j/16，两个micro求和；若返回均值，先还原对应图数的和，避免二次缩放。有效batch16不等同一次前向16图的BatchNorm/目标归一化统计，数值检查按相同micro分组比较。

EMA在本阶段第u次成功更新后使用d(u)=.9999×(1−exp(−u/2000))；浮点参数/buffer按EMA=d×EMA+(1−d)×raw更新，非浮点buffer复制raw。raw/EMA/优化器状态均完整FP32留存。

### 3.3 学习率与增强

单阶段R/R+S及新短两阶段的每个阶段均独立使用峰值LR=.001、最低LR=.00001、warmup K=100。令该阶段成功更新j=1..U：

```text
j <= K: LR(j) = .001*j/K
        momentum(j) = .8 + (.937-.8)*j/K
j > K:  LR(j) = .001*[.01 + .99*(1+cos(pi*(j-K)/(U-K)))/2]
        momentum(j) = .937
```

阶段0不更新参数。每阶段使用其实际U完成整个衰减，不截取其他长调度的前缀。历史长预算首阶段的.01学习率只用于复现原协议，不是新短实验默认值。

HSV=.015/.4/.4，degrees0/translate.05/scale.25/shear0/perspective0，fliplr.5/flipud0；mosaic、mixup、copy_paste、多尺度和TTA关闭。图像、targets与ignore共用几何；正框按锁定8.3.237默认box_candidates过滤：w>2、h>2、面积比>.1、aspect<100，ignore仅去零面积。记录矩阵/过滤项及原因；val/test只做确定性映射，不按训练过滤规则删除GT。

## 4. BBox实验流程

### 4.1 B0：单阶段真实基线R

目的：建立可直接使用的强真实检测基线，并作为固定总预算比较的参照。

流程：公开初始化→阶段0真实评价→6563步R→末步真实评价。每步16R，累计105008R/0S，真实池2100，名义约50轮。复用已有有效R的末步与冻结记录作为参照，不重跑或把校准权重冒充新的独立结果。

预算校准的历史设计为两个公开独立起点R50/R100、只比较末步主AP并一次选择预算；校准结果与选择过程见日志，不按后续结果反复重选或把100轮中间点当独立50轮实验。

### 4.2 B1：固定总量批内混合R+S

目的：在与B0相同的6563更新/105008总图像曝光下，用S替换一半重复R曝光。

流程：公开初始化→阶段0真实评价→单阶段6563步批内混合→末步真实评价。每micro8为交错4R4S，两个micro每步8R8S，最终52504R+52504S；单一SGD和EMA，不加前S或后R阶段。R/S各自固定采样流，每步预留8+8，后端成功后双游标共同提交；失败时不猜某一域已提交。

两域采用相同损失归一化，图数1:1不意味着梯度各占一半。主比较B1−B0；真实唯一标注池仍为2100，所以R曝光减半不称节约标注。当前已冻结的B1保持其实际500间隔/15份完整cp与两次评价；未来新实验使用第9节1000间隔规则。

### 4.3 B2/B3：固定总量短R→R与短S→R

目的：用匹配的短两阶段对照，区分前阶段来源效应与阶段重启效应，避免额外训练量主导比较。

| 项目 | B2 短R→R | B3 短S→R |
|---|---|---|
| 起点 | 公开YOLO11s | 同公开YOLO11s独立初始化 |
| 第一阶段 | 1500步R_extra，24000R | 1500步S，24000S |
| 第二阶段 | 5063步R，81008R | 5063步R，81008R |
| 总更新/曝光 | 6563 / 105008R | 6563 / 81008R+24000S |
| 每阶段调度 | K100，.001完整cosine至.00001 | 相同 |
| 阶段承接 | raw→新SGD/EMA | 相同 |
| 评价 | 两阶段各0/末，共4次真实750图 | 相同 |
| 完整检查点 | first3份+final7份，共10份 | 相同 |

1500步对应约一遍合成池，是预算依据而非最优切点。两项均从公开起点完整训练，不继承旧S3000、R3000或其他已训练前缀。第一阶段RR使用独立R_extra流，SR使用S流；两项末阶段都从同一个预固定R流的0位置消费81008次。增强随机流、loader状态与切阶段规则显式绑定；不能由请求顺序相同推定全部梯度/RNG轨迹相同。

具体流程：公开初始化/首阶段0保存与评价→1500成功更新及首阶段末EMA评价→承接raw/重建SGD和EMA/保存并评价终阶段0→5063成功更新→末步EMA评价与终验。前阶段末EMA和后阶段0重建EMA即使global_update相同也保留独立tag。

执行顺序为B1完整闭合后B3，再B2；B2不依赖B3分数。主比较为B3−B2；B2−B0描述阶段拆分整体效应，B3−B0描述固定总预算的实用价值。B3真实曝光较少，此设计不同时匹配真实曝光，不以此单独声称节约标注。

### 4.4 历史长预算的解释范围

长R→R和长S→R的参考结构为first30187+final6563=36750更新；首阶段峰值.01、warmup500，终阶段峰值.001、warmup100，各完整衰减并阶段重建。长RR为588000R，长SR为482992S+105008R。它们可作同长预算的来源比较，不能与B0直接解释成同训练量收益，也不能单独分离过拟合、高LR和阶段重建的因果。原始运行参数、结果和失败收据均见日志与run，不重新执行。

### 4.5 B4/B5：短预算强基线与混合配对

目的：以完整短程调度检验混合收益是否依赖真实基线训练过长。既有两阶段首阶段1500步只是已观察开发线索，不能事后充作新的独立R1500；两项重新从同一公开YOLO11s独立初始化，不继承已训练前缀。

| 项目 | B4 单阶段R1500 | B5 单阶段R+S1500 |
|---|---|---|
| seed/真实唯一池 | 17 / 原2100图 | 17 / 同2100图 |
| 更新/有效batch | 1500 / 16 | 1500 / 16 |
| 每步/累计曝光 | 16R；24000R/0S | 8R8S；12000R/12000S |
| micro | 两个micro8全部R | 两个micro8各交错4R4S |
| 调度 | 单阶段warm100，LR .001完整cosine至.00001 | 相同 |
| 优化/增强 | 第3节参数、原损失归一化 | 相同，无额外域权重 |
| 评价/模型选择 | 0/末各真实750val，固定末步EMA | 相同 |
| 完整checkpoint | 0/1000/1500三份，受控边界额外留存 | 相同 |

流程：CPU核验→独立有界机械准入→实际完整资源Gate→公开初始化/阶段0保存评价→1500成功更新→末步保存真实评价→小控制封存/owned和GPU退出验收。先B4后B5，不因分数取消另一项。R沿固定R采样流，混合沿原8R8S事务与域采样规则；唯一真实标注池相同，重复R曝光不同，不称节约标注。

完整报告每方法1500及已有6563两个固定末步，先列同1500、同6563配对差，再列每方法两个候选预算的开发选择结果。两方法各只允许这两个候选机会，不从其余checkpoint或弃用诊断挑best，不增第三切点/LR搜索。此选择仍使用已开发750图，冻结后才独立确认，不能把被选择开发成绩当无偏确认结果。

### 4.6 确认证据与扩展顺序（设计，未执行）

1. **配对训练随机性**：在seed17的100%/50%/25%/10%曲线完整收口后，seed29和43分别复现四档的R和固定1:1混合，共16项。各项固定1500步，数据子集仍是seed17冻结的同一精确UID，只改变初始化/增强/采样/loader的训练seed；不重新抽子集。逐seed、逐标注档列绝对AP及配对差、均值/标准差；三seed不自动代表统计显著。不重跑6563或两阶段矩阵。
2. **独立比赛确认**：固定24个模型（3seed×4档×2方法）末步EMA，对现canonical test game8与game9各750检测图评价一次，共48模型-比赛评价/36000图。train game4/7/11、开发game6，与game8/9比赛身份不交；同场clip全部同评价面板。game9有历史观察，game8也有元数据/下载和GT结构核验历史，均保留访问史，不称首次盲测。旧SNMOT-116属于game7、187属于game11，与当前训练比赛重叠，不可用作独立比赛。方法、模型集合、类别/ignore、阈值、UID、GT版本与原生预测范围在读取确认GT/图像前冻结；先逐比赛/seed/标注档列绝对值及差，再作固定汇总，不能用相邻帧当独立比赛样本。只评价既有模型，不在确认比赛再训练或调参。
3. **低标注证据**：第5节固定10%/25%/50%/100%嵌套曲线，使用同等对照开发机会，区分同标注量增益与达到全量R水平；未预定目标/可接受损失界限不报告标注节约通过线。
4. 合成多样性/规模、额外架构和容量留作后续机制与泛化验证，不在本轮自动执行。

## 5. 低真实标注实验

### 5.1 目标与固定预算对照

以10%/25%/50%/100%的目标真实标注池建立R与固定1:1混合的性能曲线，比较同标注量增益及相对全量R的性能差距。所有方法固定1500成功更新，来自既有双方同等两个预算候选的开发选择；本块不再根据低标注结果追加预算、LR或比例搜索。

| 真实标注档 | 唯一真实图 | 纯R总更新/曝光 | 混合总更新/曝光 | seed17处理 |
|---|---:|---|---|---|
| 100% |2100|1500 / 24000R|1500 / 12000R+12000S|复用已闭合两组|
| 50% |1050|1500 / 24000R|1500 / 12000R+12000S|新增两组|
| 25% |525|1500 / 24000R|1500 / 12000R+12000S|复用已闭合两组|
| 10% |210|1500 / 24000R|1500 / 12000R+12000S|新增两组|

## 6. Seg：足球人物实例分割准备方案

### 6.1 任务与来源

目标为整图人物可见实例mask，框与mask联合预测；Player和Referee均映射person，与BBox只评球员/门将的语义明确区别。真实训练候选为ihelon/football-player-segmentation v1（512图），外部足球开发候选为quantigoai/soccer-dataset v1（847帧/3视频）。来源间完整比赛独立性、媒体可用性与标注完整性仍须核验，没有官方split时不随机逐帧80/20，视频分片不冒充独立比赛。

### 6.2 重复与自交多边形的可追溯处理

原COCO/图像/mask只读。精确重复要求同图/同类且除annotation ID外全部字段一致，保留最小ID并记录被合并ID、源SHA与相等依据；高IoU或肉眼相似不能自动合并。

自交以明确的proper-crossing规则审计，报告源annotation ID与交点/几何问题，不直接认定所有自交像素标签都错。保留两种未启用候选：严格候选将受影响的整图隔离；像素保持候选按固定COCO光栅语义将原polygon转为压缩RLE。后者只改表示，不作人工修正；保留原area/bbox及其他字段，面积差只审计，不自动覆写。

每个派生实例需可追溯到源文件SHA、原polygon、原/新分割SHA、保留/合并/隔离原因和工具版本。禁止buffer(0)、凸包、跨碎片桥接或模型预测代替GT。人审后若需排除，原则上整图处理或先实现合法ignore，不能删一个目标却把它作为背景。各方法必须使用同一冻结视图，不能按分数选GT修正版本。

### 6.3 CPU与训练适配流程

1. 映射Player/Referee→person0；显式处理Ball/GoalLine/Field等非目标，未知类别拒绝。
2. 读取原COCO polygon/RLE或合成整数实例mask；背景0与身份映射明确，同一人物的断开区域/孔洞保持为同一实例。
3. 原RGB/框/mask同步几何，mask使用离散采样；过滤与消失实例按规则记录，不桥接轮廓。
4. 以独立实例二值mask组批，候选mask_ratio=2、overlap_mask=False；验证小目标、孔洞、多连通区域和人物重叠处理。
5. 接入真实Seg criterion、增强、完整恢复、EMA、loader/RNG与标准Mask AP；数据适配通过不等于Trainer可训练。

### 10.2 硬件与存储预算

GPU单任务、与UE互斥。BBox沿960FP32/micro8/workers2，保留GPU至少1GiB；AMP、microbatch/worker搜索、compile、多卡或同卡并发均需独立数值/资源方案，不由硬件利用率自行启用。Seg/Pose候选只能在对应GT与实现准入后测，不把BBox显存/输出大小当其测量。

所有主线大证据直接G:/FutsalMOT_Training/runs/<group_id>；D仅源码/环境/公开权重、输入缓存和runs小控制，双端RUN_LOCATION绑定，无junction或整个run搬运。D小控制预算32MiB并另保留100GiB，G需该作业完整新增上界并另保留100GiB；缓存已占空间按实际计，不重复虚增预留也不挤占安全余量。

BBox空间按实测完整checkpoint×1.1、计划cp数、每步日志2MiB上界、每次750图native每图6650344B加JSON1MiB、一次750图失败partial、瞬态3GiB+2cp计算。新两阶段按10cp/4val重算，当前混合原冻结预算不回写；Seg/Pose输出上界另测。不得删除旧失败、降低输入/更新或少存预测通过Gate。

历史混合与短SR/RR各最多3小时；本次20个1500步独立训练各最多90分钟，自各自runtime开始不因恢复重置；用实测吞吐与冷启动/验证/写盘余量逐项准入。独立比赛确认每个模型-比赛评价最多900秒，48项完整预测上界277161120000B（258.1264GiB）另加一次失败partial/瞬态及G100GiB保留，须在训练收口后按当时实际剩余空间和已有评价测量单独冻结，不能沿训练空间预算冒称评价已准入；不删除旧证据或缩减预测绕Gate。所有后续项仍须能够在原全局界限内完整闭合。全局截止2026-11-07T23:55:00Z，最多原504轮/7天，更早者为准，不派发预计无法完整闭合的作业。不自动延期或重给整段预算。

### 10.3 完成、失败与停止

成功须同时满足：规定更新/曝光/末步评价/全部cp和小收据一致，G小control_manifest为SEALED并逐小SHA通过，owned controller/wrapper/worker按真实创建时间和命令核退出、GPU锁退休且无未知写者。训练status COMPLETE不单独代表整体收口；不全哈模型/NPZ/媒体。

失败、人工取消或未知提交保留全部证据，低分不是重跑理由。真正基础设施问题最多一次明确同协议有界修订，预算不重置；不自动恢复人工取消、回滚或重放未知更新。当前有限批量链为seed29/43各四档R与混合的16项；全部闭合后停止该训练队列，再按第5节固定24末EMA/两比赛48次确认的独立准入流程执行评价。任一训练失败/人工取消/未知提交时暂停后项而不自动恢复；不扩新的seed、比例、预算、型号、来源或Seg/Pose训练。
