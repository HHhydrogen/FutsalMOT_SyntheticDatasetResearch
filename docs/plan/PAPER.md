# 论文方向

更新：2026-10-31。本文件持续原地更新，不建立日期归档或V1/V2副本。当前负责研究设计，不在此启动训练或改变活动生成。

## 核心问题

同一足球仿真过程产生的BBox、人物实例mask、COCO17、球衣号码和连续身份标注，能否补充真实监督，改善真实比赛感知与追踪？贡献以真实实验逐项确认，不预设五个任务全部有效，也不把多字段直接等同算法创新。

旧训练仅作预实验。正式图像模型从核验的公开预训练起点独立开始，不续训旧项目权重、关联MLP、优化器或预测缓存。S→R可以承接本轮S阶段权重。

## 证据主线

| 问题 | 必要对照与证据 | 可写结论 |
| --- | --- | --- |
| 单项标注的真实迁移价值 | 同公开起点R与S→R，加入训练量与策略对照 | 仅对具有合法真实GT且实际验证的任务主张贡献 |
| 收益是否跨容量存在 | YOLO11 n/s/m/l/x的预登记比较 | 报全部尺寸，不挑最大上涨规格 |
| 检测收益是否进入MOT | 不同检测器接同一追踪配置 | 说明前端变化，不能直接称关联器学会身份 |
| 结构线索是否帮助身份 | 固定检测，分别加入预测mask/Pose/号码及组合 | 哪项有增量才给哪项记功，缺失线索有回退 |
| 时序ID是否超出单帧监督 | 同帧源的单帧与连续ID监督对照，另定时序预算 | 未执行则不宣称连续ID训练的独立贡献 |

长边视角、绿色地面、号码外观、4K和标准点序是质量与适用性属性，不单独作为创新。数据生成阶段完成的质量/覆盖验收直接引用，研究阶段不反复重扫媒体或重复像素审计。

## 指标与解释范围

检测用BBox AP50:95，分割用Mask AP50:95，合法COCO17参考下用OKS AP，号码用整轨迹完整号码准确率；完整MOT主要HOTA，固定检测身份实验主要AssA，并报DetA/IDF1/IDSW。不同任务不合成一个总分。

按比赛、来源和全部训练seed保留绝对成绩，再给配对差与适当区间。只有一两场测试比赛时明确样本少，区间按描述性解释；相邻帧不是独立比赛。已观察/重划分测试不能称首次盲测。跨库关系未认证时只能按数据方案限定的来源内实验解释。
