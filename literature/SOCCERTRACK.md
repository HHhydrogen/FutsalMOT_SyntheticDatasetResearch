# SoccerTrack 与 SoccerTrack v2

- SoccerTrack原工作：*A Dataset and Tracking Algorithm for Soccer with Fish-eye and Drone Videos*；[作者仓库](https://github.com/aemis2024/SoccerTrack)。含wide-view、top-view/无人机及GNSS等多源足球数据。仓库曾注明数据修订历史，使用时应核实版本和校验。
- SoccerTrack v2：Atom Scott 等，*SoccerTrack v2: A Full-Pitch Multi-View Soccer Dataset for Game State Reconstruction*，arXiv:2508.01802；[arXiv](https://arxiv.org/abs/2508.01802)，[作者项目页](https://atomscott.github.io/SoccerTrack-v2/)。报告10场大学足球比赛、934分钟、固定全场景panoramic 4K录制及游戏状态标签（场上坐标、球衣号、角色、球队）和事件。
- 对本项目：真实足球数据的相机分布不限于电视广播角落视角，也已有全场景/多视角和球衣号数据。可用来研究“视角覆盖”或补充真实域，但不是新test前先查具体比赛重叠和许可。
- 限制：固定全景和目标长边广播在人物像素尺寸、遮挡、镜头运动方面差异大；数据论文/技术报告状态、许可及可下载范围在研究冻结前复核。
