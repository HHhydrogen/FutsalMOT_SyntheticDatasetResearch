# MOTSynth

- 论文：Matteo Fabbri 等，*MOTSynth: How Can Synthetic Data Help Pedestrian Detection and Tracking?*，ICCV 2021, pp.10849–10859；[arXiv](https://arxiv.org/abs/2108.09518)，[CVF论文PDF](https://openaccess.thecvf.com/content/ICCV2021/papers/Fabbri_MOTSynth_How_Can_Synthetic_Data_Help_Pedestrian_Detection_and_Tracking_ICCV_2021_paper.pdf)。
- 贡献：使用游戏引擎生成多样的合成人群序列，研究检测、ReID、分割和多目标追踪的合成监督，并展示合成数据在若干真实任务上的可用性。
- 对本项目：提供“从3D引擎联合产生检测/追踪标注，再跨域评估”的方法学先例；应将时序、身份和困难事件设计在同一个可控数据生成系统里。
- 限制：行人城市场景不是足球比赛；不能拿它的结论替代足球域的真实验证，也不能声称通用合成数据必然有益。
