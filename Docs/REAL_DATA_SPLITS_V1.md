# 真实数据来源与比赛级split草案 v1

## 选取原则

- split单位是完整比赛，严禁同一比赛的片段、机位、剪辑或不同转码落到不同split。
- 新test需确认比赛身份此前未用于模型/协议选择。原SNMOT-116/187及封存test包继续封存；原来已观察的12场全部属于development，不能改名为新test。
- 划分训练、开发、封存测试，并保留足够多独立比赛以计算比赛级差值区间。数量由可用许可/资源和统计计划决定，先审来源、再锁定。
- 真实test要覆盖普通推进/传接球、一般接触交叉、拥挤定位球/强遮挡等层级；按全比赛抽样后在比赛内标事件panel，不只挑简单片段提高分数。
- 训练/验证可有相同难度分层但不能共享比赛。困难事件定义和抽样规则在查看模型测试结果前冻结。

## 候选来源

1. **SoccerNet-Tracking**：足球tracking数据和比赛序列；优先审查新比赛ID、可用分割、数据许可与当前项目12场的重合。相同benchmark公开test若以前已被当前模型看过，则不再是本研究的封存test。
2. **SportsMOT**：含足球、篮球、排球的视频追踪基准，可作为跨赛事/场景开发来源；足球序列范围和许可单独核对。不能把多运动数据聚合成“足球比赛数”。
3. **SoccerNet-GSR**：200段足球视频含球员位置、队伍、角色和号码，但任务标注/视角和本项目MOT契约不相同。可用于号码和真实长边广播域审计；如需作为训练来源，须明确转换规则和来源切分。
4. **新采集五人制比赛**：若能取得被摄者许可，最贴近目标域；需固定相机/收音剪辑信息、授权、标注协议、比赛级身份和隐私管理。

本轮不下载大型视频、不抓取测试标注、不作任何训练。先做许可、身份和历史使用记录，再选择候选。对研究代码/权重开放不代表数据本身可自由再分发。保留来源URL、许可条款日期和原始数据ID，但不把受限媒体放Git/G盘公共目录。

## 难度分层

推荐每场都计算总体MOT指标，并报告三个事件panel：

- 常规：球员间交叠低、单人主体尺度清楚、无持续静态聚集。
- 中等交互：多人近距离、动态交叉或短时遮挡。
- 高难：定位球/门前拥挤、显著互相遮挡、多人出入画或镜头快速运动。

具体判据转化为可计算阈值前冻结，例如人框交并面积/遮挡率、可见人数、ID切换机会与相机运动；不能基于模型错误定义难度。分层是辅助分析，主要结果仍按完整比赛统计，避免把很多高度相关帧当独立样本。

## 报告表

每个方法至少给出每场绝对HOTA/DetA/AssA/IDF1/MOTA、场均macro和协议定义下pooled/micro结果；同一场的成对差值及以比赛为重采样单位的95%区间；普通/中等/困难panel分数和样本比赛数。检测和关联分别评估时，注明固定检测缓存、类别、阈值和track生命周期。公开论文分数只作为背景，不能跨不同数据/协议直接排名。
